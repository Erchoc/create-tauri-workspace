# __PROJECT_DISPLAY_NAME__

A cross-platform Tauri 2 desktop application generated by
`create-tauri-workspace`.

## Prerequisites

- Bun 1.3 or newer
- Rust stable
- The platform prerequisites from the Tauri documentation

## Development

`bash
bun install
bun run dev
`

Useful commands:

`bash
bun run frontend:dev
bun run check
bun run build
`

## Structure

`text
apps/desktop/     React and Vite frontend
crates/app/       Tauri shell and commands
crates/core/      Framework-independent application logic
crates/common/    Shared data models
crates/platform/  Platform information and OS-specific adapters
crates/storage/   Local application data paths
crates/updater/   Update channel policy
resources/        Native resources bundled with the app
installers/       Installer customization
scripts/          Build and packaging entry points
docs/             Architecture and release notes
`

Read [docs/development.md](./docs/development.md) before changing the app and
[docs/distribution.md](./docs/distribution.md) before publishing binaries.

## Before the first release

Replace the placeholder identifier `__PROJECT_IDENTIFIER__` in
`crates/app/tauri.conf.json` with a reverse-domain identifier you control, and
replace the generated app icon.
